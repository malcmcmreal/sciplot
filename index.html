Calculated columns

Make a new column from others, e.g. 90 - `Angle from Horizontal` or Dpar / Dper. Put names with spaces in `backticks`; np.sin, np.degrees, np.abs etc. work.

Plot

Choose a text column to split one series into groups, or leave as “(series)” to compare the Y series side by side.

Plot options

X column → angle, Y column(s) → distance from the centre. X label labels the arc, Y label the radius.

Each bar is coloured by that statistic of the chosen column for the rows in the bin. Colour map and range are under Colour, size & shape.

Colour, size & shape

Map columns onto the points (scatter and line + markers).

Direction “none” uses the point's angle on a polar plot. Colour comes from Colour by.

What to track

Values are drawn in a random order without replacement; the plot shows the statistic of the first n as measurements are added.

Filters

A Dpar range simulates measuring only within that window; a dash-dot line shows the value before the cut, so you can see any bias it introduces.
