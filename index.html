Logic

Write column names in "quotes" (plain one-word names work without). ^ is power. Whole-column functions give every row the same value (e.g. "Dpar" - mean("Dpar")); per-group ones use a second column as the group, e.g. groupmean("Dpar", "Sheet"). Formulas can use columns made above them. Results must be numbers; use where(cond, 1, 0) for flags.

What to track

Values are drawn in a random order without replacement; the plot shows the statistic of the first n as measurements are added.

Filters

A Dpar range simulates measuring only within that window; a dash-dot line shows the value before the cut, so you can see any bias it introduces.
